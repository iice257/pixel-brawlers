# Original brief (2026-10-16)

Raw intent, lightly cleaned up.

- Getting into game dev seriously. First project: a simple 2D sprite fighting game, web-based, quick to build, to post as a demo and a teaser for making 2D games.
- Nothing copyrighted. Inspired by the Mortal Kombat 1 style: multiple characters, character picker, story mode.
- Goes on GitHub and into the portfolio.
- Own repo, own folder. Include media files, brainstorm files, scratchpad, the website (playable), and a README.
- Separately: add the Scroll Swift chart videos to the portfolio under motion design. The portfolio is meant to be stacked with work.

## Decisions made while scaffolding
- Stack: vanilla JS + Canvas, ES modules, no build step (zero-friction for GitHub Pages).
- Art: procedural pixel puppets for the demo, sprite sheets later.
- Characters, names, story and audio are original.
- Repo name: `pixel-brawlers`.
